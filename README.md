# AM Signal Simulator (Python)

## 📌 Description
This project simulates an amplitude modulated (AM) signal based on user inputs.

## 🚀 Features
- Generates AM signal values
- User-defined frequencies and modulation index
- Time vs signal output

## 🧠 Concepts Used
- Principles of Communication
- Amplitude Modulation (AM)
- Python math functions

## ▶️ How to Run
Run:
python main.py
